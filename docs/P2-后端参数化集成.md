# GameScreen P2 后端参数化集成指南

## 概述

P2 功能对齐中，所有前端参数化配置均通过 **GsLotteryConfig.extra** JSON 字段存储，使用现有后端接口即可完成持久化。

## 后端支持现状

### ✅ 已支持接口

#### 1. 保存抽奖配置
```java
// GameScreenService.saveLotteryConfig()
POST /gamescreen/lotteryConfig/save
{
  "id": 1,
  "activityId": 100,
  "plugName": "ydj",
  "theme": "default",
  "extra": "{...}"
}
```

#### 2. 查询抽奖配置
```java
// GameScreenService.listLotteryConfigs()
GET /gamescreen/lotteryConfigs?activityId=100
Response: [{ id, activityId, plugName, theme, extra }, ...]
```

#### 3. 保存活动配置
```java
// GameScreenService.saveRedpacketConfig()
POST /gamescreen/activity/save
{
  "id": 100,
  "extra": "{...}"
}
```

## 前端参数化字段规范

### 摇大奖 (ydj) - extra 字段

```json
{
  "title": "第1轮摇大奖",
  "ydjDuration": 60,
  "ydjStatus": "2",
  "ydjSkin": "default",
  "mobileShakeImage": "/images/shake.svg",
  "prizeIds": [1, 2, 3],
  "rounds": [
    {
      "id": 1,
      "ydjStatus": "2",
      "ydjDuration": 60,
      "title": "第1轮"
    }
  ]
}
```

**支持皮肤**:
- `default` - 默认绿色
- `golden` - 金色豪华
- `red` - 喜庆红
- `dark` - 暗色神秘

---

### 抽奖 (cjx/zjd) - extra 字段

```json
{
  "title": "幸运抽奖",
  "fontColor": "#FFFFFF",
  "prizeFontColor": "#FFD700",
  "winnerFontColor": "#00FF00",
  "leftColor": "#4CAF50",
  "rightColor": "#FF69B4"
}
```

---

### 3D 抽奖 (threedimensional) - extra 字段

```json
{
  "title": "3D 抽奖",
  "sphereColor": "#FFD700",
  "sphereGlossiness": 0.8,
  "sphereMetalness": 0.6,
  "cardBgColor": "#FFFFFF",
  "cardBorderColor": "#DDD",
  "cardBorderWidth": 2,
  "ambientLightColor": "#FFFFFF",
  "ambientLightIntensity": 0.6
}
```

---

### 开幕/闭幕 (kaimu/bimu) - 内容页面 extra 字段

```json
{
  "fullscreen": true,
  "kaimuTransition": "fade",
  "bimuTransition": "zoom",
  "revDelay": 5000,
  "revTransition": "fade"
}
```

**支持过渡类型**:
- `fade` - 淡入/淡出
- `slide-up` - 上滑进入/下滑退出
- `slide-down` - 下滑进入/上滑退出
- `slide-left` - 左滑进入/右滑退出
- `slide-right` - 右滑进入/左滑退出
- `zoom` - 放大/缩小
- `rotate` - 旋转进入/旋转退出
- `bounce` - 弹跳进入
- `flip` - 翻转进入/退出

---

### 红包 (activity) - extra 字段

```json
{
  "redpacketSpeed": 1.5,
  "redpacketDensity": 1.2
}
```

**参数范围**:
- `redpacketSpeed`: 0.5 - 2.0 (1.0 = 基础速度)
- `redpacketDensity`: 0.5 - 2.0 (1.0 = 基础密度)

## 前端保存流程

### 1. 抽奖参数保存

```javascript
// gamescreen-wall/src/App.vue

// 读取用户配置
const extra = lotteryExtra(plugName)

// 修改参数（示例）
extra.ydjSkin = 'golden'
extra.ydjDuration = 90

// 保存到后端
await api('/gamescreen/lotteryConfig/save', {
  method: 'POST',
  body: JSON.stringify({
    id: configId,
    activityId: activityId,
    plugName: plugName,
    extra: JSON.stringify(extra)
  })
})

// 立即刷新数据
await loadSnapshot()
```

### 2. 红包参数保存

```javascript
// 修改活动红包参数
const activity = snap.value.activity
activity.extra = activity.extra || {}
activity.extra.redpacketSpeed = 1.5
activity.extra.redpacketDensity = 1.2

// 保存
await api('/gamescreen/activity/save', {
  method: 'POST',
  body: JSON.stringify(activity)
})
```

## 数据库升级建议

目前所有参数均存在 `extra` JSON 字段中，**无需数据库结构变更**。

建议记录参数变更日志：

```sql
CREATE TABLE IF NOT EXISTS gs_config_audit (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  activity_id BIGINT,
  plug_name VARCHAR(50),
  field_name VARCHAR(100),
  old_value VARCHAR(1000),
  new_value VARCHAR(1000),
  operator_id BIGINT,
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

## 前端使用文档

### 在 App.vue 中读取参数

```javascript
// 摇大奖皮肤
const ydjSkin = computed(() => lotteryExtra('ydj').ydjSkin || 'default')

// 红包参数
const redpacketSpeed = computed(() => 
  Number(activity.value.extra?.redpacketSpeed) || 1
)

// 3D 抽奖材质
const lottery3dMaterials = computed(() => 
  lotteryExtra('threedimensional')
)
```

### 在组件中应用参数

```javascript
// YdjScene.vue
<YdjScene 
  :skin="ydjSkin"
  :duration="ydjDuration"
/>

// RedpacketScene.vue
<RedpacketScene 
  :speed="redpacketSpeed"
  :density="redpacketDensity"
/>

// Lottery3D.vue
<Lottery3D 
  :extra="lottery3dMaterials"
/>
```
