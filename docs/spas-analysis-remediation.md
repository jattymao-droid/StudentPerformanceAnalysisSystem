# 知脉 · 学情分析功能整改说明

> 编写日期：2026-10-16  
> 范围：学生分析、班级分析、知识点分析、考查频次、反复薄弱、预警取数、实考校次对照展示  
> 代码基线：`ruoyi-spas` 分析引擎 + `ruoyi-ui/src/views/spas/analysis/*` + `application.yml` → `spas.analysis`  
> 互补：算法评估见 [`spas-analysis-algorithm-evaluation.md`](./spas-analysis-algorithm-evaluation.md)；准确度见 [`spas-core-accuracy-evaluation.md`](./spas-core-accuracy-evaluation.md)  
> 后续优化（快照空白置零 / 补弱入口 / 多维摘要等）见 [`spas-analysis-optimization.md`](./spas-analysis-optimization.md)

---

## 1. 整改目标

主公式不改：加权掌握度仍由 `KnowledgeStatCalculator` 统一计算；正式薄弱仍是「低掌握 + 作答次数达到门槛」。

本轮要改的是**教师读结论的方式**：

1. 正式薄弱为 0 时，同一屏能看见综合低分与样本不足，并写明当前学科的次数门槛。
2. 章节薄弱人数、考查频次「优先干预」与正式薄弱分列，页面标明「不等同正式定级」。
3. 校次只解释统考进退，不与掌握度卡片混读。
4. 年级/校级范围、预警窗口、标注覆盖不足时，结论区有明确限制说明。

**不纳入本轮：** IRT、错因自动挖掘、家长 App、在线考试。错因标签继续只作题目备注，不进入加权率。

## 2. 问题与整改项

### A. 结论区并列三指标（P0）

| 项 | 现状 | 目标 |
| :--- | :--- | :--- |
| A1 | 班级/学生主 KPI 突出「正式薄弱」。学期内每点 attempt 常 &lt; 3 时，班均偏低但正式薄弱为 0 | 摘要区固定并列：**正式薄弱 / 综合低分 / 样本不足**，并显示「正式定级至少 N 次」（N 取当前学科 `min-attempts`） |
| A2 | 分科门槛不一致：MATH/CHN/ENG 为 3，PHYS/CHEM 关注与薄弱可为 2、严重仍为 3，页面不展示 | 结论条展示当前学科代码与门槛；物理/化学写明「严重仍须达到 severe-min-attempts」 |

**落点**

- 前端：`ruoyi-ui/src/views/spas/analysis/class.vue`、`student.vue`
- 后端：`SpasAnalysisServiceImpl` / `KnowledgeStatQueryService` 摘要已有相关计数字段则复用；缺字段时在 overview/summary 增加 `minAttempts`、`severeMinAttempts`、`subjectCode`
- 配置：`ruoyi-admin/src/main/resources/application.yml` → `spas.analysis.subject-overrides`、`weak-thresholds`

**验收**

- 仅一场月考、知识点 attempt &lt; 门槛时：正式薄弱可为 0，综合低分与样本不足不为空说明。
- 切换数学与物理，门槛数字随学科变化。

### B. 旁路指标与正式薄弱脱钩说明（P0）

| 项 | 现状 | 目标 |
| :--- | :--- | :--- |
| B1 | 章节「薄弱人数」按章节率 &lt; 薄弱线统计，**不看**作答次数（`KnowledgeStatQueryService` 注释已写明） | 班级章节表标题或列头注明「按得分率，非正式薄弱」 |
| B2 | 考查频次优先干预：题次 ≥ `priority.question-min`（默认 2）且班均 &lt; `weak-rate`（默认 0.60），不要求正式薄弱门槛 | 交叉卡片副标题写明规则；与正式薄弱数字不一致时不视为故障 |
| B3 | 综合低分不看次数 | 学生/班级 KPI 旁短注：「综合低分 ≠ 正式薄弱」 |

**落点**

- `class.vue` 章节汇总
- `frequency.vue` 考查×掌握交叉
- `student.vue` 摘要

**验收**

- 正式薄弱为 0、优先干预 &gt; 0 时，频次页能读到「本象限不要求达到正式定级次数」。

### C. 校次与掌握度分栏（P0）

| 项 | 现状 | 目标 |
| :--- | :--- | :--- |
| C1 | 学生页校次轨迹与掌握度并排，文案已区分，仍易把校次读成掌握度 | 校次卡片独立分组，标题为「实考校次（不参与知识点掌握度）」；无小题成绩时掌握度区显示空态：「本学科暂无小题成绩，雷达与正式薄弱不可用」 |
| C2 | 仅有统考总分/校次的学科仍可能被当成学情完整 | 空态引导到「实考校次」或提示先导入小题成绩 |

**落点：** `student.vue`；必要时班级页校次入口同样加一句范围说明。

**验收：** 无 `spas_score_detail` 的学科打开学生分析，不出现可被当成「掌握良好」的空白雷达默示。

### D. 标注覆盖与质量（P0，以提示为主）

| 项 | 现状 | 目标 |
| :--- | :--- | :--- |
| D1 | 未标注占比 &gt; 20% 时降置信并禁止正式定级（`annotation-coverage`） | 被拦截时结论区展示 `formalWeakBlockReason`，并链到质量看板对应试卷 |
| D2 | 权重和、题型、Bloom 已有导入门禁；覆盖率不拦发布 | 本轮不把覆盖率升为发布硬门禁；在分析空态/拦截态写明「请先补标注」 |

**落点：** `student.vue`、`class.vue` 已有 Alert 处补跳转；`quality/index.vue` 深链沿用 `paperId`。

**验收：** 覆盖率超阈值时，正式薄弱不出现定级标签，且能一键打开质量看板。

### E. 范围与窗口对齐（P1）

| 项 | 现状 | 目标 |
| :--- | :--- | :--- |
| E1 | 选年级/校级部门时统计含下级，差班被稀释 | 班级分析在含下级时，KPI 下固定提示「含下级班级，干预名单请改选具体班」 |
| E2 | 预警默认按 `default-window`（本学期），与教师当前页窗口可能不一致 | 从分析页跳转「立即预警」或文档约定：预警执行带上当前 `window`；分析页增加「预警按本学期」的短注（若当前窗不是学期） |
| E3 | `window=all` 读快照，本学期/选卷为即时聚合 | 口径条已有；补充「改标注后请重算，否则『全部』可能仍是上次快照」 |

**落点**

- `class.vue`（已有年级提示处加强）
- `WarningEngine`、预警执行入口、分析页跳转 query
- 口径 Alert：`class.vue`、`student.vue`、`knowledge.vue`

**验收**

- 年级节点查询时提示可见。
- 分析页为「近 30 天」时，用户能看到预警列表未必同口径。

### F. 可解释配置（P1）

| 项 | 现状 | 目标 |
| :--- | :--- | :--- |
| F1 | 实测难度：≥8 人时与配置难度各半（`empirical-blend: 0.5`），跨过人数线会轻微改率 | 分析配置接口带回 `empiricalEnabled`；学生/班级口径条在开启时加一句「难度含班级实测校正」 |
| F2 | 一题多点默认按权重分摊（`allocation-mode: proportional`） | 口径条保留「一题多点为辅助定位，非分技能实测」 |
| F3 | 空白置零默认关；勾选后 0 分进入掌握度 | 分析摘要若本窗口存在 `score_source=3`，提示「含空白置零，解读掌握度时请剔除」 |

**落点：** `application.yml`、`/spas/analysis/config`、分析页口径条；`score_source=3` 计数若摘要没有则在 live 聚合补计数字段（只展示，不改公式）。

### G. 交互补齐（P2）

| 项 | 现状 | 目标 |
| :--- | :--- | :--- |
| G1 | 学生页雷达、成绩趋势无点击；薄弱条可下钻 | 雷达点/趋势点至少能打开对应知识点题目抽屉，或提示「请用薄弱列表下钻」并保证列表可达 |
| G2 | 干预复评默认异步，刚导入看效果会滞后 | 干预效果区已有异步时，学生页干预标签旁提示「效果可能稍后更新」 |

**落点：** `student.vue`、`SpasChart` 的 `chart-click`（班级页已接，学生页补齐或明确不做并写在口径里）。

## 3. 实施顺序

| 批次 | 内容 | 优先级 |
| :--- | :--- | :---: |
| 1 | A1、A2、B1、B2、B3、C1 | P0 |
| 2 | D1、E1、E2 | P0–P1 |
| 3 | E3、F1、F2、F3 | P1 |
| 4 | G1、G2 | P2 |

批次 1 只改展示与文案字段，**不调整** `weak_level` 计算公式，避免历史预警与干预基线被静默改写。

---

## 4. 明确不改

- 不把「综合低分」自动升级为正式薄弱。
- 不把章节薄弱人数改成 `weak_level` 计数（避免与现有章节图口径断裂）；只加标注。
- 不把考查频次象限改成与 `min-attempts` 完全相同；只声明差异。
- 不把实考校次写入 `spas_score_detail` 或掌握度快照。
- 覆盖率保持软门禁（降置信 + 禁正式定级），不改为发布硬拦截。

---

## 5. 验收剧本

1. **少样本：** 某班某科仅一次测验。正式薄弱 = 0，综合低分或样本不足有数，页面写出至少 N 次才定级。
2. **分科门槛：** 同一学生看数学与物理，N 与配置一致。
3. **旁路：** 章节表与频次「优先干预」能读到「非正式薄弱」。
4. **无小题：** 只有校次的学科，掌握度区为空态，校次区仍可看轨迹。
5. **脏标注：** 未标注占比超阈值，正式定级被拦，并可跳到质量看板。
6. **年级：** 选年级时出现「含下级」提示。
7. **回归：** `KnowledgeStatCalculator` 现有单测保持通过；本轮不改加权公式时不必改期望值。
