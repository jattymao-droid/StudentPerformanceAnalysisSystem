# 反复薄弱演示脚本（S 系列）

> 对应 [`spas-multi-exam-weak-plan.md`](./spas-multi-exam-weak-plan.md)  
> 目的：用最少数据验证「多场低掌握 → 反复薄弱」判定，不新增快照表。

## 前置

- 物理学科 + 若干叶子知识点已入库  
- 配置默认：`spas.analysis.persistent-weak.min-papers=3` / `rate-threshold=0.60` / `persist-ratio=0.67`

## 造数（3 场卷 × 2 生）

1. 建同一班级、同一学科下 **3 份** 分析卷（草稿→发布），每卷至少 1 小题绑定同一叶子知识点 K。  
2. 学生 A：三场该点得分率均 **&lt; 0.60** → 应进入反复薄弱。  
3. 学生 B：仅 1～2 场低于阈值 → **不应** 进入（persist-ratio 不满足）。

## 核验

| 入口 | 期望 |
| :--- | :--- |
| 学生分析 → 反复薄弱 | A 含知识点 K；B 不含 |
| 班级分析 / 报告 | 口径条注明时间窗或选卷；与分析页一致 |
| 改 `rate-threshold` 后重查 | 名单随配置变化（即时聚合，无缓存表） |

## 清理

演示后可删除三场卷及成绩，或保留作回归样本。
