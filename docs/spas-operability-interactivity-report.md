# 知脉 · SPAS 操控性与交互性评估报告

> 评估日期：2026-09-18  
> 评估范围：`ruoyi-ui/src/views/spas/**`、首页仪表盘、相关 API 与链路跳转  
> 参照基准：教师/教务常规操作场景；与 `docs/spas-evaluation-report.md`（功能/准确度）互补  
> 结论摘要：**教师主闭环（导入→分析→预警→干预→档案）链路跳转较完整，反馈与口径提示做得好；图表交互不均衡，报告预览缺失，CRUD/移动端体验偏弱。综合：可支撑试点校日常操作，尚未达到「分析产品级」交互体验。**

---

## 1. 评估维度与口径

| 维度 | 定义 | 观测点 |
| :--- | :--- | :--- |
| **操控性** | 用户能否高效完成目标任务（选人/选班/导入/干预/修复） | 筛选门槛、必填引导、权限门控、确认与撤销、空状态指引、链路跳转 |
| **交互性** | 系统对操作的响应与探索能力 | 图表点击、下钻、页签/卡片、加载/成功失败反馈、深度链接、响应式布局 |
| **非目标** | 不评家长 App、在线作答、E10 错因 | 仅评现有 Web 管理端 |

样本：18 个 `views/spas` 页面 + `views/index.vue` 首页仪表盘；以代码静态审阅为主（未做真人用户测试）。

## 3. 任务闭环：操控性地图

```text
Home KPI/guide
  |- paper -> score import (?paperId)
  |- score -> class analysis / warning record
  |- class analysis -> student / knowledge (chart/table)
  |- student analysis -> portfolio / intervene
  |- warning record -> intervene / analysis / portfolio
  |- intervene -> student analysis
  |- quality -> score / paper / ticket
  `- student list -> portfolio
```

**操控亮点**

1. **门槛引导清晰**：多数分析页用 `el-empty` 要求先选学生/班级/知识点/试卷。
2. **危险操作有确认**：重算、撤销批次、发布/归档、干预评估/关闭、预警立即执行等均有 `$modal.confirm`。
3. **成绩→分析路径短**：试卷「去导入」、成绩「去分析/预警」。
4. **首页作为控制面**：KPI/`goIfPerm` 按权限跳转；学生角色自动进「我的学情」。

**操控痛点**

1. **质量修复落点粗**：仅跳到成绩/试卷列表，无法定位到具体题目/批次。
2. **报告无独立页**：仅下载；API 已有 preview，前端未接入预览。
3. **频次优先象限无动作**：无直达干预或知识点分析。
4. **首页近期批次表不可点**：与 KPI 可点不一致。

## 4. 交互性分模块评估

### 4.1 分析域

| 页面 | 操控 | 交互 | 评价 |
| :--- | :---: | :---: | :--- |
| 班级 `analysis/class.vue` | 高 | **最高** | 薄弱柱/热力图 `@chart-click`；排名→学情 |
| 学生 `analysis/student.vue` | 高 | 中 | 表格 drawer/干预；图表**无点击** |
| 知识点 `analysis/knowledge.vue` | 中 | 中低 | 表格跳学情为主 |
| 考查频次 `analysis/frequency.vue` | 中 | **低** | 优先象限**无行动作** |

`SpasChart` 已支持 `chart-click`，但仅班级页接线——**交互能力未在分析域复用**。

### 4.2 业务闭环

| 页面 | 亮点 | 缺口 |
| :--- | :--- | :--- |
| 试卷 | 权重校验、发布/归档确认 | 对话框信息密集 |
| 成绩 | 批次下钻、错误日志 | 「去分析」未挂 `v-hasPermi` |
| 预警 | 立即执行、一键干预 | 无批量处理 |
| 干预 | 基线/效果/辅导日志 | 筛选缺班级 |
| 质量 | 卡片下钻 + 工单（P2） | 修复无定位参数 |
| 开放 | 状态横幅（P2） | 无联调面板 |

### 4.3 档案与学生端

| 页面 | 评价 |
| :--- | :--- |
| 一生一册 | 筛选+导出完整；图表不可点 |
| 我的学情 | 只读、交互最弱（无导出/深链） |

## 5. 反馈与可感知性

| 模式 | 使用 | 评价 |
| :--- | :--- | :---: |
| `$modal.msg*` | CRUD/校验/失败 | 高 |
| `$modal.confirm` | 危险操作 | 高 |
| `el-alert` | 口径/公式/置信度/Open 开关 | **优秀** |
| `el-empty` + `v-loading` | 门槛与加载 | 高 |

学生/班级页口径 Alert 降低「误用结论」风险，属于**操控安全性**。

---

## 6. 权限门控

| 密度 | 页面 |
| :--- | :--- |
| 高(8-12) | student / subject / knowledge / paper / open / teacher |
| 中(5-6) | score / warning / quality / portfolio / student分析 / intervene |
| 低(1-4) | class / knowledge分析 / frequency |
| 无 | portfolio/mine |

问题：部分导航按钮未挂权——**可见性与可执行性不完全一致**。

---

## 7. 响应式

- **较好**：分析摘要卡、图表双列、质量卡、首页 KPI。
- **较弱**：CRUD 页固定宽对话框、密集操作列。
- **结论**：定位为**桌面教研工具**，不应以手机巡课为主场景承诺。

## 10. 建议验收剧本

1. 首页 KPI 点击进入对应菜单，无权限时不误跳。
2. 试卷→导入→去分析，班级/学科自动带入。
3. 班级热力图点击可选学生或知识点下钻。
4. 预警→干预→学情，参数不丢。
5. 质量卡片下钻→创建工单→工单页可查。
6. 未选学生/班级时仅见 empty。
7. 重算/撤销必有确认；取消无侧效。
8. Open 横幅与 `spas.open.enabled` 一致。
