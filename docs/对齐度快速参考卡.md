## 🎓 关键知识点速查

### 原项目的三大基础
1. **PHP MVC 框架** (Loader 模式) → 复刻用 **Spring Boot**
2. **Smarty 模板引擎** → 复刻用 **Vue3 组件**
3. **MySQL 关系型** → 复刻用 **PostgreSQL**

### 复刻版的三大优势
1. **前后端分离** → 独立迭代、团队协作高效
2. **实时推送** → WebSocket 替代轮询、低延迟
3. **微服务就绪** → 模块化代码、易于扩展

### 对齐难度排序
1. **简单** ✅: API 响应、数据字段 (已完成)
2. **中等** 🟡: 视觉参数、动画配置 (可补齐)
3. **困难** ❌: 音效库、原生 JS 兼容 (需专项投入)
