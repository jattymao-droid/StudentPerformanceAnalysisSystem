# 微信 OAuth 与红包付款联调指南

## 1. 环境变量

在部署环境或 `application.yml` 中配置（也可在若依 **活动大屏 → 微信配置** 页面填写，写入 `sys_config` 并优先生效）：

```yaml
gamescreen:
  mock-wechat: false          # 生产关闭 mock
  wechat:
    appid: ${GS_WX_APPID}
    secret: ${GS_WX_SECRET}
  wxpay:
    enabled: true             # 启用真实企业付款
    mch-id: ${GS_WX_MCH_ID}
    api-key: ${GS_WX_API_KEY}
    cert-path: ${GS_WX_CERT_PATH}   # apiclient_cert.p12 绝对路径
```

| 变量 | 说明 |
|---|---|
| `GS_WX_APPID` | 公众号 AppID |
| `GS_WX_SECRET` | 公众号 AppSecret |
| `GS_WX_MCH_ID` | 微信支付商户号 |
| `GS_WX_API_KEY` | 商户 API 密钥 |
| `GS_WX_CERT_PATH` | 商户证书路径（企业付款到零钱） |

## 2. 公众号网页授权（H5）

1. 登录 [微信公众平台](https://mp.weixin.qq.com) → 设置与开发 → 公众号设置 → 功能设置  
2. 将 H5 域名加入 **JS 接口安全域名** 与 **网页授权域名**（仅域名，不带协议和路径）  
3. H5 入口带活动 ID：`https://your-domain/?activityId=1`  
4. 微信内访问：`https://your-domain/?activityId=1&wechat=1`  
5. 后端接口：`GET /gs/auth/h5/wechat` 返回授权 URL，回调 `GET /gs/auth/h5/wechat/callback`

本地开发可继续使用 mock：`POST /gs/auth/h5/mock`（`gamescreen.mock-wechat: true`）。

**注意：** 授权回调后 H5 会保留 `?activityId=` 参数；`redirect_uri` 需与公众号后台授权域名一致。

## 2.1 后台联调自检

若依 **活动大屏 → 微信配置** 页点击 **联调自检**，或调用：

`GET /gamescreen/wechat/diagnose`（需 `gs:wechat:query` 权限）

返回 `issues` / `checks` 列表，用于上线前核对 Mock、证书、密钥等项。

## 3. 红包企业付款

1. 开通微信支付 **企业付款到零钱**  
2. 上传 `apiclient_cert.p12` 到服务器，配置 `GS_WX_CERT_PATH`  
3. 设置 `gamescreen.wxpay.enabled=true`  
4. 后台开启红包轮次后，观众 H5 抢红包将走 `WxRedpacketPayAdapter`  
5. 未启用时默认记账模式（`payStatus=mock`，不实际打款）
6. 实付模式下 `openid` 必须以真实微信授权获得（非 `mock_` 前缀）

### 摇大奖 legacy 流程

1. 大屏勾选「原 front_ydj.js 皮肤」
2. 点击「开始游戏」→ 自动将 H5 状态设为进行中（`ydjStatus=2`）
3. 观众 H5 摇手机中奖 → legacy 大屏轮询展示中奖名单
4. 倒计时结束或点击重置 → 状态回到未开始/已结束

## 4. 大屏口令

- 默认口令：`screen123`（可在若依「活动配置」修改）  
- 大屏 URL：`https://your-domain/?activityId=1`（端口 5173 开发环境）

## 5. 常见问题

| 现象 | 处理 |
|---|---|
| 授权后跳回白屏 | 检查授权回调域名与 H5 实际域名一致 |
| `redirect_uri 参数错误` | 公众号后台未配置网页授权域名 |
| 付款失败 | 确认商户证书、API 密钥、账户余额与付款权限 |
| 对对碰池为空 | 观众签到时需选择性别（男=1，女=2） |

## 6. H5 本地开发与功能联调

### 6.1 Vite 代理

`gamescreen-h5/vite.config.js` 已将 `/gs`、`/common` 代理到 `http://localhost:8080`。启动顺序：

1. 后端 `ruoyi-admin`（8080）
2. `gamescreen-h5`（5174）
3. 浏览器访问 `http://localhost:5174/?activityId=1`

### 6.2 Mock 登录与微信模式

| 场景 | URL / 操作 |
|---|---|
| 本地 Mock | 打开 H5 → 填写昵称 →「进入活动」（`gamescreen.mock-wechat: true` 或后台开启 Mock） |
| 微信内 OAuth | 关闭 Mock 后，微信内打开 `?activityId=1` 将**自动跳转**授权；也可手动加 `&wechat=1` |
| 生产守卫 | Mock 关闭时 `POST /gs/auth/h5/mock` 返回错误；实付红包拒绝 `mock_` openid |
| 活动切换 | URL 带 `activityId` 或管理端配置 `h5EntryUrl` |

### 6.3 摇大奖 / 竞速游戏

| 功能 | 后台配置 |
|---|---|
| 摇大奖 | **抽奖玩法** → 插件 `ydj` → extra `ydjStatus=2`（进行中） |
| 摇大奖图 | 同页 `mobileShakeImage` 可填手机摇动图 URL |
| 竞速游戏 | **竞速游戏** 开启场次；H5 游戏 Tab 可勾选「原手机皮肤」 |
| 中奖概率 | `ydj` extra `winChance`（1–100） |

H5 摇大奖 Tab 右上角 **更多** 与全站弹层共用；游戏原皮肤 iframe 内 **更多** 通过 `postMessage` 唤起同一弹层。

### 6.4 签到二维码与二次进入

管理端 **活动配置** 上传「签到二维码图」→ 写入 `qrcodeUrl`；H5 **更多** 弹层底部展示，与原版 `app_footer` 收藏区一致。未上传时按 `h5EntryUrl?activityId=` 在线生成。
