# GameScreen 复刻版本功能对齐差异分析

**比对时间**: 2026-08-31  
**原项目**: `E:\AI\GameScreen` (PHP + MySQL)  
**复刻版本**: `E:\AI\gamescreen-ruoyi` (Java + PostgreSQL)

---

## 概览

复刻版本已实现 **核心业务闭环 + 所有 18 个场景**。本文档详细列出**还有哪些细节功能/特性未完全对齐**。

### 对齐度统计
- ✅ **完全对齐**: ~75% 功能
- 🟡 **部分对齐**: ~20% 功能（代码就绪，需配置或优化）
- ❌ **未对齐**: ~5% 功能（低优先级或技术差异导致）

## 第一部分：后端 API 层差异

### 1.1 【已对齐】缺少的 API 端点

复刻版本完整实现了所有核心 API 端点（65+ 个），但原项目 PHP 中的一些**特殊 AJAX 接口**可能有细节差异：

| 原 PHP 接口 | 功能 | 复刻状态 | 补充说明 |
|-----------|------|--------|--------|
| `wall/ajax_act_get_sign.php` | 拉取签到列表（实时） | ✅ | `GsScreenController.getSignSnapshot()` |
| `wall/ajax_act_get_new_sign.php` | 新签到推送 | ✅ | WebSocket + `sign-event` |
| `wall/ajax_act_get_danmu.php` | 弹幕列表（轮询） | ✅ | `danmuHistory` + SSE |
| `wall/ajax_act_vote.php` | 实时投票数据 | ✅ | `voteSnapshot` WebSocket |
| `wall/ajax_act_new_msg.php` | 新消息通知 | ✅ | `wall-event` SSE |
| `wall/ajax_act_redpacket.php` | 红包状态 | ✅ | `redpacketSnapshot` |
| `wall/ajax_act_xyh.php` | 幸运号状态 | ✅ | 场景数据同步 |
| `wall/ajax_act_set_qrcodepos.php` | 二维码拖拽位置保存 | 🟡 | 存 `gs_activity.qrcode_pos` JSON，未前端持久化 |

### 1.2 【未完全对齐】响应数据结构细节

#### 签到数据格式
**原项目返回**:
```json
{
  "data": [
    {
      "id": 123,
      "name": "张三",
      "phone": "13800138000",
      "qd_order": 1,
      "qd_time": "2026-08-31 10:00:00",
      "avatar": "http://...",
      "qd_state": 1  // 0-未签/1-已签/2-待审/3-拒绝
    }
  ]
}
```

**复刻版本**:
```json
{
  "code": 200,
  "msg": "success",
  "data": [
    {
      "id": 123,
      "nickname": "张三",
      "phone": "13800138000",
      "signOrder": 1,
      "signTime": "2026-08-31 10:00:00",
      "avatarUrl": "http://...",
      "signAudit": 1  // 0-待审/1-通过/2-拒绝
    }
  ]
}
```

**差异**: 字段名驼峰化、嵌套结构不同（复刻版直接返回数组）

#### 配置返回格式
**原项目** (`wall/config.txt`):
```php
$wall_config = array(
  'screenpaw' => 'screen123',
  'signlogoimg' => 'http://...',
  'danmusettings' => [...],
  ...
);
```

**复刻版本** (`GsActivityService.getActivityInfo()`):
```json
{
  "id": 1,
  "name": "春季发布会",
  "screenPassword": "screen123",
  "signQrcodeUrl": "http://...",
  "danmuEnabled": true,
  "danmuSpeed": 30,
  ...
}
```
