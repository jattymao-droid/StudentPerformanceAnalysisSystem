## 3. 算法体系总览

```
小题成绩 spas_score_detail
        │  (排除 score_source=4/5 缺考/未作答)
        ▼
 KnowledgeStatCalculator
   sample_w = 知识点权重 × 难度权重 × 近因衰减
   weighted_rate = Σ(rate×sample_w) / Σ(sample_w)
   attempt = 去重题目数
   weak_level = f(rate, attempts, 阈值)
        │
        ├─ 写入快照 spas_student_knowledge_stat   ← window=all
        ├─ 即时重算（时间窗 / 选卷）               ← semester|last*d|paperIds
        ▼
 综合得分率 / 正式薄弱 / 样本不足 / 班级对比
        │
        ├─ 学生·班级·知识点分析页
        ├─ 反复薄弱（跨场次）
        ├─ 考查频次 × 掌握度象限
        └─ 预警 / 干预
```

旁路（独立数据源）：

```
spas_exam_score（校次） → SpasExamRankTrendService → 「实考校次进退」
（仅可叠加绑定卷的掌握度，不改写校次结论）
```

## 4. 核心公式与语义

### 4.1 单知识点加权得分率

对绑定到知识点 \(k\) 的每一次有效作答 \(i\)：

\[
w_i = W_{knowledge} \times W_{difficulty} \times R_{recency}
\]

\[
\overline{r}_k = \frac{\sum_i r_i \cdot w_i}{\sum_i w_i}
\]

| 符号 | 含义 | 默认 |
| :--- | :--- | :--- |
| \(r_i\) | 该题得分率 | 导入计算 |
| \(W_{knowledge}\) | 题-知识点权重 | 卷面标注 |
| \(W_{difficulty}\) | 易/中/难：1.0 / 1.2 / 1.5；可选与班级实测难度 0.5 混合 | yml |
| \(R_{recency}\) | \(0.5^{d/T}\)，\(T=\)半衰期天 | \(T=60\)；可关 |

**作答题数**：按 `questionId` 去重。一题多知识点时，各知识点各计 1 次，但题目本身不在「综合作答题数」里重复累加（学生摘要用去重题数）。

**不计入掌握**：`score_source` 为缺考(4)、未作答(5)。空单元格默认跳过（`blank-as-zero: false`）。

### 4.2 学生「综合得分率」

在已聚合的知识点集合上做 **按作答次数加权**：

\[
\overline{R} = \frac{\sum_k \overline{r}_k \cdot a_k}{\sum_k a_k}
\]

\(a_k\) 为该知识点 attempt；若全为 0 则退化为简单平均。班级班均 = 学生综合率再平均。

### 4.3 正式薄弱等级 `weak_level`

| 码 | 条件（默认） | 中文 |
| :---: | :--- | :--- |
| 3 | \(\overline{r}<0.45\) 且 attempts≥3 | 严重 |
| 2 | \(\overline{r}<0.60\) 且 attempts≥3 | 薄弱 |
| 1 | \(\overline{r}<0.75\) 且 attempts≥3 | 关注 |
| 0 | 其余 | 正常 / **未达到正式定级门槛** |

### 4.4 置信度

\[
c = 1 - \frac{1}{1 + a / a_{min}},\quad a_{min}=3
\]

展示标签（考查频次/明细侧）：attempt&lt;3 → **样本不足**；3–5 → 中；≥6 → 高。

### 4.5 关键概念对照（易混点）

| 概念 | 判定 | 可否作正式定级 |
| :--- | :--- | :---: |
| **正式薄弱** | `weak_level`∈{1,2,3} | 是 |
| **综合低分 / lowRate** | \(\overline{r}<0.60\)（不看出答次数） | 否 |
| **样本不足 / thinSample** | 低分且 attempts&lt;3 | 否 |
| **反复薄弱** | 跨多场试卷低分占比≥约 2/3，且有效场次≥3 | 作稳定薄弱参考 |
| **选卷诊断** | 仅在所选试卷集合上即时聚合 | 标注覆盖不足时可强制样本不足 |
| **实考校次** | 导入校次排名，与小题无关 | 进步/退步看排名数字变小/变大 |

## 5. 三种计算口径

| 条件 | dataMode | 数据源 | 特点 |
| :--- | :--- | :--- | :--- |
| `paperIds` 非空 | `papers` | 小题明细即时 | 诊断某几场；受标注覆盖率门禁 |
| window∈{semester,last30d,last90d} | `live` | 小题明细 + 考试日起点 | 默认 **本学期**；近因按「今天」衰减 |
| window=`all` | `snapshot` | `spas_student_knowledge_stat` | 依赖最近一次重算；含重算时近因 |

**一致性评价**：live/papers 与快照 **共用同一聚合公式**——这是架构上的主要正确决策。差异来自「纳入哪些考试」与「快照是否过期」，而非两套互相矛盾的加权法。

**默认窗口风险**：`default-window: semester` 导致多数页面走 live。若学期内小题少（如仅一场月考、每知识点 attempt 常 &lt;3），会出现「班均偏低但正式薄弱全 0」——属规则执行正确，但必须靠文案与「综合低分」卡片解释。

## 6. 分模块算法评估

### 6.1 学生分析

| 能力 | 算法要点 | 评价 |
| :--- | :--- | :--- |
| 摘要卡片 | 综合率、班均/名次/百分位、正式薄弱、置信度 | 口径清晰；无小题学科会空卡片 |
| 自动切学科 | 无数据时建议有 `score_detail` 的学科 | 已补齐，降低「默认语文无数据」误判 |
| 薄弱 Top | 正式薄弱优先，可填充低分样本不足 | 需分清标签 |
| 反复薄弱 | 跨卷趋势打标 | 有效场次不足时正确标样本不足 |
| 实考校次 | 独立管道 | 与掌握度并排展示，文案已区分 |

**风险**：用户仍可能把「校次 644」读成「掌握度很好」；依赖 Alert 文案。

### 6.2 班级分析

| 能力 | 算法要点 | 评价 |
| :--- | :--- | :--- |
| 班均 / 正式薄弱 / 综合低分 | live 与快照均按正式薄弱计人；另计综合率&lt;60% 人数 | 已对齐并补「综合低分」 |
| 薄弱知识点数 | 有关注/薄弱/严重人数，或班均&lt;0.75 | 偏宽，易大于「正式薄弱知识点」直觉 |
| 章节汇总 | 叶子 attempt 加权上卷到章节 | 合理降噪 |
| 热力图 | 矩阵为加权率 | 人多知识点多时前端限列/加高 |

**样例（5 班·物理·本学期，评估日数据）**：学生 58，班均 ≈56.4%，正式薄弱 0，综合低分 40，样本不足未定级 58，薄弱知识点约 19。说明：**规则门禁生效，不是算错成全班正常。**

### 6.3 知识点分析

| 能力 | 算法要点 | 评价 |
| :--- | :--- | :--- |
| 全部/版本/章节下钻 | 版本·章节·全部以快照汇总为主；叶子可走 live | 范围大时用快照可接受，但与「本学期」条并存时需读 `scopeNote` |
| 下级柱状图 | 子节点班均 | 横坐标须 `interval:0`（已修） |
| 班级对比 | 多班 avgRate | 依赖部门范围与权限 |

### 6.4 考查频次 × 掌握度

| 象限 | 条件（默认） |
| :--- | :--- |
| 优先干预 | 关联题数≥2 且 avgRate&lt;0.60 |
| 稳固 | 题数≥2 且 avgRate≥0.75 |
| 证据不足 | attemptAvg&lt;3 或无率 |
| 关注 | 其余 |

掌握度默认与所选试卷集合一致（避免「频次看选卷、掌握看全量」的历史混读）——评价为 **正确修复**。

### 6.5 反复薄弱

- 有效场次 ≥ `min-papers`(3)  
- 低分场：该场该知识点率 &lt; 0.60  
- 低分场占比 ≥ `persist-ratio`(0.67) → **反复薄弱**  
- 另有单次探底 / 波动型 / 稳定  

与单场 `weak_level` 正交，适合筛「多次都差」的干预对象。

### 6.6 预警与干预

| 模块 | 算法要点 | 评价 |
| :--- | :--- | :--- |
| WarningEngine | AVG_RATE / WEAK_COUNT / 低于班均 / 连续下降 / 反复薄弱 / 校次下滑等 | 指标覆盖面够；**按默认分析窗口取数**，未必等于教师当前页选择 |
| Intervene | 基线冻结加权率；复测 Δ；目标默认 0.60 | 与掌握度引擎对齐；选卷标注不足时前端可拦正式定级 |

### 6.7 实考校次

- 输入：多次统考校次导入  
- 输出：轨迹、较上次/首次、与总分偏差标签  
- **不参与** `weighted_rate` / `weak_level`  

评价：产品定位正确；需持续用文案防止与掌握度卡片混读。

## 8. 优点

1. **单一引擎**：快照与 live/papers 同公式，避免「重算一套、页面又一套」。  
2. **证据门禁明确**：正式薄弱与样本不足分离，符合中学「少样本不下结论」原则。  
3. **三维口径**：全量 / 时间窗 / 选卷，满足备课诊断与阶段复盘。  
4. **可解释链条**：知识点 → 题 → 考试日/难度/权重；干预可算 Δrate。  
5. **校次与掌握度解耦**：统考排名与小题诊断各说各话，减少统计口径污染。  
6. **配置外置**：阈值与半衰期可运维调校，无需改代码。  
7. **选卷标注门禁**：未标注过高时降置信、阻正式定级，抑制脏数据定论。

## 10. 准确度边界（如何正确使用）

**适合**：

- 找出本学期/某几场考试中「考得多但不会」的知识点  
- 在样本足够时给正式薄弱定级与干预清单  
- 用章节汇总压叶子噪声；用校次看统考进退  

**不适合**：

- 仅 1～2 道题、attempt&lt;3 就认定「该生该点薄弱」  
- 用掌握度卡片解释「校次数字」  
- 无小题成绩的学科（仅有统考总分/校次）期待雷达与正式薄弱  
- 将系统输出直接挂钩升学选拔或处分  

**教师操作建议**：

1. 先确认学科有小题+知识点标注。  
2. 看口径条：本学期即时 vs 全部快照 vs 选卷。  
3. 正式薄弱为 0 时，先看综合低分与「样本不足」人数，再决定是否加练/加测。  
4. 选卷诊断前检查未标注占比。  
5. 导分或改标注后执行重算，再看 `all` 快照。

## 13. 总评

SPAS 学情分析算法已形成 **可配置、可解释、快照与即时同源** 的掌握度主模型，并在正式薄弱、样本不足、选卷诊断、反复薄弱、频次×掌握度、校次旁路上形成完整教学闭环。当前最大准确度瓶颈不是公式错误，而是：

1. **小题与标注是否充分**；  
2. **教师是否理解「正式薄弱 ≠ 综合低分 ≠ 校次」**；  
3. **标注覆盖与样本量是否达标**（工程硬编码/缺测风险已收敛）。

在标注规范、样本量达标、口径选择正确的前提下，系统可作为 **日常诊断与干预筛选工具** 使用；综合算法成熟度评为 **A-（约 8.2 / 10）**。
