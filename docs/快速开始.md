## 🎯 常见配置任务

### 配置摇大奖皮肤为金色

1. **后台编辑摇大奖**
   - 打开后台管理系统
   - 编辑活动 → 摇大奖配置
   - 设置 `extra` JSON:
   ```json
   {
     "ydjSkin": "golden",
     "ydjDuration": 90
   }
   ```

2. **保存配置**
   - 点击保存
   - 前端自动应用新皮肤

### 调整抽奖颜色

```json
{
  "fontColor": "#FFFFFF",        // 参与者名字 - 白色
  "prizeFontColor": "#FFD700",   // 奖品名称 - 金色
  "winnerFontColor": "#00FF00",  // 中奖者 - 绿色
  "leftColor": "#4CAF50",        // 左侧背景 - 绿色
  "rightColor": "#FF69B4"        // 右侧背景 - 粉色
}
```

### 设置开幕/闭幕动画

在内容管理中编辑开幕/闭幕页面：

```json
{
  "kaimuTransition": "zoom",     // 开幕 - 缩放进入
  "bimuTransition": "slide-down" // 闭幕 - 下滑退出
}
```

**支持的过渡类型**:
- `fade` - 淡入/淡出
- `slide-up/down/left/right` - 方向滑动
- `zoom` - 放大/缩小
- `rotate` - 旋转
- `bounce` - 弹跳
- `flip` - 翻转

## 🔧 开发者指南

### 添加新参数

#### 前端

1. **App.vue 中添加 computed**
   ```javascript
   const newParam = computed(() => {
     const extra = lotteryExtra('plugName')
     return extra.newParam || defaultValue
   })
   ```

2. **在组件中使用**
   ```vue
   <YourComponent :new-param="newParam" />
   ```

#### 后端

1. **在管理后台设置 extra JSON**
   ```json
   {
     "newParam": "value"
   }
   ```

2. **调用保存接口**
   ```bash
   POST /gamescreen/lotteryConfig/save
   ```

### 调试参数

#### 浏览器控制台

```javascript
// 查看当前摇大奖配置
```

## 🐛 常见问题

### Q1: 参数修改后不生效？

**A**: 检查以下步骤:

1. ✅ 确认 JSON 格式正确 (使用 jsonlint.com 验证)
2. ✅ 确认参数字段名拼写正确
3. ✅ 硬刷新浏览器 (Ctrl+Shift+R)
4. ✅ 检查浏览器控制台是否有错误

### Q2: 皮肤样式没有应用？

**A**: 

1. ✅ 检查 CSS 变量是否定义
2. ✅ 确认 z-index 是否正确
3. ✅ 清除浏览器缓存
4. ✅ 查看是否有 CSS 冲突

### Q3: 动画卡顿？

**A**:

1. ✅ 检查浏览器硬件加速是否启用
2. ✅ 减少页面上的动画数量
3. ✅ 检查 GPU 使用情况 (DevTools → Performance)

### Q4: 手势识别不准？

**A**:

1. ✅ 确认滑动距离 > 50px
2. ✅ 检查浏览器是否禁用触摸事件
3. ✅ 尝试在不同设备上测试
4. ✅ 查看触摸事件是否被其他元素拦截
