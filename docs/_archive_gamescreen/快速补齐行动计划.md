### 1.1 音效库补齐（优先级最高，直观提升用户体验）

#### 任务 1: 红包雨音效库
**现状**: 大屏红包雨无音效  
**目标**: 补充掉落、拆包、中奖音效

**实现步骤**:
```
1. 获取原项目音频资源
   - 文件位置: E:\AI\GameScreen\wall\themes\meepo\assets\sounds\ (如有)
   - 或从网络免费音效库下载
   
2. 处理音效文件
   - 格式: MP3/WAV（<50KB，避免加载慢）
   - 时长: 0.3-0.5 秒（避免过长）
   - 库: redpacket_fall.mp3 / redpacket_open.mp3 / redpacket_win.mp3
   
3. 复制到前端资源
   - 目录: gamescreen-wall/public/assets/sounds/
   - 命名: redpacket-*.mp3
   
4. 大屏组件集成
   - 文件: gamescreen-wall/src/components/RedpacketScene.vue
   - 添加 Audio 标签或 new Audio() 播放
   - 掉落时播放 redpacket_fall.mp3（loop）
   - 拆开时播放 redpacket_open.mp3
   - 中奖时播放 redpacket_win.mp3
```

**代码示例**:
```vue
<script setup>
const soundFall = new Audio('/assets/sounds/redpacket-fall.mp3')
const soundOpen = new Audio('/assets/sounds/redpacket-open.mp3')

const playRedpacketFall = () => {
  soundFall.volume = 0.3
  soundFall.play()
}

const playRedpacketOpen = () => {
  soundOpen.volume = 0.5
  soundOpen.play()
}
</script>
```

**工时**: 2-3 小时  
**检验**: 大屏切到红包雨场景，听到掉落/拆开声音

### 1.2 交互反馈增强（P1 级别）

#### 任务 4: 游戏排行排名变化动画
**现状**: 游戏排行更新无视觉反馈  
**目标**: 排名上升/下降时有闪烁/箭头动画

**实现步骤**:
```
1. 数据结构优化
   - 记录排名前一帧的位置
   - 计算排名变化 (Δrank = rank_old - rank_new)
   - Δrank < 0: 上升（绿色箭头 ↑）
   - Δrank > 0: 下降（红色箭头 ↓）
   
2. 动画实现
   - 文件: gamescreen-wall/src/components/GameScene.vue
   - CSS 动画: @keyframes rankUp / rankDown
   - 闪烁效果: opacity 0.5 → 1 → 0.5（500ms）
   - 持续 2 秒后恢复正常
   
3. 样式
   .rank-up { color: green; animation: rankUp 2s; }
   .rank-down { color: red; animation: rankDown 2s; }
```

**工时**: 3-4 小时

## 五、关键风险与应对

| 风险 | 影响 | 应对 |
|------|------|------|
| 音效文件缺失 | 无法补充音效库 | 从网络免费库下载或自录 |
